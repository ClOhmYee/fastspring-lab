# FastAPI 기반 서버 구성

## 동기

1. 이전에 Python을 적극 활용하여 다양한 프로젝트를 진행했었으나, 프레임워크(Django, FastAPI 등)를 활용한 경험은 없음

2. 과제를 수행하며 단일 책임 원칙(SRP) 등 객체 지향 프로그래밍(OOP)을 최대한 고려한 프로젝트를 진행하는 것이 중요하다고 생각함

3. 이전에 진행하고자 계획했지만 시간 상 진행하지 못 한 개인 프로젝트의 축소판으로 계획하여 이어 도전하고자 함

## 기능

1. 기본적인 서버를 구축

2. Spring Boot 서버로부터 데이터를 받고 그에 맞는 값을 전송

## 이슈

1. Java에서 활용한 JUnit처럼, Python에서 사용 가능한 pytest를 활용해 테스트를 진행하기 위해 활용법을 숙지하여 활용함

2. Spring Boot 서버와의 원활한 통신을 위해 CORS 메커니즘에 대해 이해하고, 해당 개념을 활용하기로 결정함

    하지만 최종적인 테스트 과정에서 지속적인 오류 발생과 그 원인 분석에 많은 시간이 소요됨에 따라, 우선 간단한 기능 구현을 위해 CORS Middleware와 message의 크기를 줄여 구현하기로 결정함

3. 지속적으로 Spring Boot 서버에서 보내는 POST 요청을 FastAPI 서버에서 제대로 인식하지 못 하는 문제가 발생해, 전반적인 코드를 재작성하는 것으로 결정함

    이에 따라 Spring Boot 서버와 FastAPI 서버를 모두 재작성함

4. 단일 책임 원칙을 최대한 준수하기 위해 Spring Boot 서버에서 POST 요청을 받아 메세지를 분류하는 기능과 그 메세지를 Spring Boot 서버로 전송하는 기능을 분류하려 했으나, 하나의 파일에서 해당 과정을 확인하고자 receive.py에 합치기로 결정함
